# 画像更新（Portrait）

**主画像只有一个写入者：本技能。** 其他场景只能往"画像参考"里投观察——这是防止画像被污染的唯一办法。

## 结构：主画像 vs 参考

| 文件 | 谁写 | 性质 |
|---|---|---|
| `10-shared/宿主画像.md` | **只有本技能**，且必须宿主确认后落盘 | 稳定认知，≤8KB |
| `10-shared/画像参考.md` | 所有场景，只追加 | 零散观察，允许冗余 |

**流程是单向的**：参考 → 提炼 → 候选画像 → 宿主确认 → 主画像。反向不允许（主画像不许直接抄参考）。

## 步骤

1. **读参考**：读 `画像参考.md` 全部（一般不长），标记出"重复出现 ≥2 次"的观察。
2. **归类到六个维度**（对齐 UP 主的偏好分类）：
   - **交互偏好**：称呼、格式、语言、给结论还是给推理
   - **工具偏好**：什么事找什么工具/场景
   - **文件偏好**：路径习惯、命名习惯、临时文件放哪
   - **协作偏好**：要不要确认、要不要 dry-run、能不能自己拍板
   - **安全偏好**：禁区、不许碰的东西、隐私等级
   - **记忆偏好**：什么该记、什么别记
3. **写候选**（不是直接改主画像）：在回复里列出"拟新增 / 拟修改 / 拟删除"三栏，**每条附证据**（来自哪几次观察）。
4. **等宿主确认**。宿主说"就这样"→ 才落盘。宿主改哪条就只改哪条。
5. **落盘**：覆盖写 `宿主画像.md`，格式固定：

```markdown
# 宿主画像（更新于 YYYY-MM-DD）

## 交互偏好
- 先给结论再给依据（证据：3 次要求"直接说结果"）

## 工具偏好
- …

## 安全偏好
- L1 内容永不出网；L2 需逐条确认（来源：宪法）
```

6. **清理参考**：把已经升级进主画像的观察，从 `画像参考.md` 移到 `90-archive/画像参考-已提炼-<日期>.md`，参考文件保持"只有未提炼观察"的状态。

## 硬约束

- 主画像 ≤ 8KB，超了必须合并同类项，不许无限膨胀。
- **不许写推测**：不写"宿主可能是个完美主义者"这种没有行为证据的判断。
- **不许写敏感值**：画像里可以写"在意家庭隐私"，不许写家人的姓名/病情/住址。
- 每次更新都要留痕：旧版本复制到 `90-archive/portrait-<日期>.md`，可回滚。
- 宿主说"这条不对" → 立刻改并记住"不要这样推断"，写进记忆偏好。

## 预期效果（C 阶段的验收点）

宿主开启本技能后，连续使用 2–4 周，应出现：
- 新会话几乎不需要重新解释背景（B 信号的量化入口）
- 你的回复默认格式与宿主习惯一致，不需要每次纠正
