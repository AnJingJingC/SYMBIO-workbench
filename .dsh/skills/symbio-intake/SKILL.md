# 知识摄入（Intake）

把"一堆原始材料"变成"一张能检索、能复用、能被画像吸收的卡片"。这是 SYMBIO 的第一道工序，也是宿主画像唯一的粮食来源。

## 什么时候用

- 宿主给链接/文件/字幕，说"整理一下""存下来""消化掉"
- 宿主说"把这个目录里没整理过的都过一遍"
- 你自己判断：这次对话产生了值得沉淀的知识，且尚未落盘

**不适用**：纯闲聊、临时问答、宿主明确说"不用记"。

## 前置检查（按顺序，缺一步就停）

1. **读配置**：`config/symbio.config.json` → `stage.modules.intake` 必须为 `true`。
2. **读场景**：`memory/20-scenes/knowledge-digest/定位卡.md` 与 `私有记忆.md`（只读开头几段），确认这张卡片该归到哪个主题。
3. **隐私卡口（第一道）**：把原始文本交给 `/symbio-pii-guard` 扫描。
   - 命中 **L1** → 立刻终止，只回一句"内容命中硬红线，已阻断，未做任何处理"，**不要复述命中的内容**。
   - 命中 **L2** → 卡片中一律用占位符（如 `«NAME_1»`），并在卡片尾部"脱敏清单"里登记，绝不写入真值。
   - 命中 **L3** → 照常处理，同时把观察项追加到 `memory/10-shared/画像参考.md`。

## 步骤

1. **取全文**。链接 → 用可用手段取正文；文件 → 读全文；字幕 → 按段落读。取不到全文就明确说"只能拿到标题/摘要"，**不许凭标题编内容**。
2. **压成一张卡**（正文 ≤ `limits.cardMaxChars`，默认 1200 字）。结构固定：

```markdown
# <卡片标题：一句话说清这是什么>

- 来源：<链接或文件路径>
- 摄入时间：<YYYY-MM-DD HH:mm>
- 密级：<L0 公开 / L2 已脱敏>
- 主题标签：<3–6 个，用 # 开头>

## 一句话结论
<如果只记一句话，记这句>

## 要点
1. …（3–7 条，每条一行，可执行/可验证的优先）

## 原文关键片段
> <≤150 字的原文引用，用于回溯>

## 我的判断
<这张卡对宿主有什么用；和已有的哪张卡冲突或互补；拿不准就写"待验证">

## 脱敏清单
| 占位符 | 类型 | 说明 |
|---|---|---|
| «NAME_1» | 姓名 | 已在原文中替换 |
```

3. **写盘（走确定性 Worker，不许手写文件）**：把消化好的卡片正文交给摄入 Worker，由它统一执行「隐私闸(L1 硬拦) → 字数闸(≤cardMaxChars) → 防覆盖写盘 → 重建索引」。
   - 首选：直接调用本机 `tools/intake.mjs`（由宿主 Agent 在业务根执行）：
     `node tools/intake.mjs --title "<标题>" --source "<链接/路径>" --body "<卡片正文>"`
   - 或在面板「摄入长文 · 落卡」卡片里粘贴正文 → 点「落卡」（面板会 POST `/api/symbio/intake`）。
   - Worker 会自动生成 `YYYY-MM-DD-<kebab-标题>.md` 落入 `memory/20-scenes/knowledge-digest/cards/`，同名已存在则加 `-2`、`-3`，**绝不覆盖**；超字数或命中 L1 会直接拒绝并说明原因，**不要假装写成功**。
4. **确认索引已重建**：Worker 落卡后会自动跑 `node tools/index-build.mjs`；回执里自带 `index.ok`。若 Worker 不可用（面板离线条/接口 503），再退回手工在 `cards/索引.md` 追加一行：`文件名 | 一句话 | 标签`，并重跑 index-build。
5. **写回记忆**（第二道隐私卡口在前）：调用 `/symbio-memory-write`，把"这次读了什么、学到什么关于宿主的偏好"写入场景私有记忆与画像参考。
6. **回执**：给宿主三行——卡片路径、一句话结论、下一步建议。不要贴全文。

## 批量模式

宿主给一个目录时：
1. 先列清单（文件名 + 大小 + 是否已有卡片），**先给宿主看一眼再开跑**。
2. 每 10 个停一次，报进度与失败项。
3. 任何一条命中 L1 → 跳过并单独报告，不中断整批。

## 失败与降级

| 情况 | 处理 |
|---|---|
| 取不到全文 | 只做"标题级卡片"，正文写明"未取到全文，结论不可信" |
| 文本超长（> 5 万字） | 分段摘要 → 再合并；每段保留来源锚点（段落号/时间戳） |
| 模型能力不足 | 降级为"人工可执行清单"：列出该读哪几段、该记哪几条，让宿主自己填 |
| 写入失败 | 把卡片内容原样贴在对话里，并说明写入失败原因，**不要假装写成功** |

## 自查（写完必过）

- [ ] 卡片有来源和时间戳
- [ ] 没有出现任何未经脱敏的 L2 内容
- [ ] 要点可验证，不是"很重要""值得关注"这类空话
- [ ] 索引已更新
- [ ] 场景私有记忆没有超过 25KB
