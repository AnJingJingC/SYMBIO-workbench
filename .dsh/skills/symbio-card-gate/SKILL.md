# 卡片质量闸

**这张卡的来源是一次真实事故：无人循环跑完 11 秒就"成功"了，落下来的卡片只有两行——**

```
# 文件总线为什么用文件
规划知识卡片结构
```

`规划知识卡片结构` 是豆包的**思考占位语**，不是答案。整条链路 `ok: true`、退出码 0、索引正常更新，**没有任何一环报错**。所以质量闸不能靠"流程是否成功"判断，必须有一条独立于链路的判据。

## 一、什么不算答案（落卡前必查）

| 判据 | 说明 |
|---|---|
| 无句末标点且 ≤16 字 | 真实回答几乎不可能没有标点或换行；`正在思考` / `提炼消息队列核心表述` / `规划知识卡片结构` 全部落在这条里 |
| 动宾短语式摘要 | 占位语是模型自由生成的，**枚举不完**。别用前缀黑名单（`正在/规划/思考中`），这条踩过：下一个占位语是"提炼…"，黑名单直接漏 |
| 与标题重复 | 正文第一行等于卡标题 = 没有正文 |
| 含界面噪声 | `已完成思考` / `已深度思考（用时 N 秒）` / `需要我为你…` / 句末纯数字引用角标 |

**结构性判据优于词表**：`有句末标点或换行` ⇒ 正文；`无标点短句` ⇒ 占位，继续等。

## 二、合格卡片四项齐全（缺一即不合格）

| # | 项 | 判据 | 常见缺法 |
|---|---|---|---|
| 1 | 一句话结论 | `## 一句话结论` 小节下有一句完整陈述，且不等于标题 | 退化成标题本身 |
| 2 | 要点 | ≥3 条，每条是**可复述的判断**而不是"讲了什么" | 写成目录复述 |
| 3 | 原文摘录 | ≥2 段，带出处定位 | 全是转述，无法回溯 |
| 4 | 标签 | ≥3 个，用于索引检索 | 只有 1 个泛标签 |

体量参考：**400–1200 字**。低于 400 字基本是没消化；高于上限按 `limits.cardMaxChars` 截断。

## 三、执行顺序（别跳）

1. **取回答前**：对桥的返回先过"什么不算答案"——命中就重试，不是落卡。
2. **落卡前**：确认四项齐全，缺哪项就回去补那一项，**不要先落盘再补**（落盘后没人会回来补）。
3. **落卡后**：`node tools/index-build.mjs` 重建索引，检查"一句话"列**不是标题**、不是"（无摘要）"。
4. **异常处理**：实在取不到正文，如实留空并标注 `<!-- 消化失败：占位语，未落卡 -->`，**绝不拿占位语充数**。

## 四、为什么要这么严

垃圾卡片比没有卡片更糟：

- 它占着索引位，让 `symbio-recall` 检索到一段废话，污染后续所有判断；
- 它让"无人循环跑通了"变成假象——链路全绿但产出为零，比直接报错更难发现；
- 落盘后归档进 `_done`，原文不再存在于队列，等于**把原材料也弄丢了**。

**判断口径：宁可这张卡不存在并报错，也不要存在但内容是占位语。**
