# 检索召回（Recall）

**先查地图，再翻箱子。** 全量读一遍是最贵、最慢、最容易出错的检索方式。

## 检索顺序（逐层下钻，命中即停）

```
第 0 层  当前交接.md            ← 最近 1 天的进度，先看这个
第 1 层  10-shared/索引.md      ← 跨场景总地图
第 2 层  场景/cards/索引.md      ← 卡片级目录（文件名 + 一句话 + 标签）
第 3 层  场景/私有记忆.md        ← 只读开头几段
第 4 层  场景/私有技能/          ← 看 skill 目录名 + 简介，不读正文
第 5 层  90-archive/索引.md      ← 历史归档
```

每层都只读**索引/摘要**；只有确认命中，才读那一个文件的全文。

## 步骤

1. **把宿主的问法翻译成检索键**：主题词 + 时间范围 + 可能的标签。
2. **按顺序下钻**，在索引里做字符串/同义匹配（例："那个省 token 的办法" → 键：token / 省钱 / 成本 / 换会话）。
3. **命中 → 读该文件，给出**：
   - 原文关键段（≤150 字引用）
   - 出处路径（含行号或小节名）
   - 时间（这条是什么时候记的）
4. **多层都没命中 → 直接说**："没查到。我查了 交接 / 共享索引 / 卡片索引 / 私有记忆 / 归档索引，都没有匹配。" 然后给两个选项：①换关键词再试 ②确认后新建一条记忆。
5. **顺手补索引**：如果发现某个目录下文件很多但没有索引，跑 `node tools/index-build.mjs`。

## 置信度标注（必须给）

| 标注 | 含义 |
|---|---|
| **高** | 在对应索引中精确命中，且有出处路径 |
| **中** | 语义相近，可能不是同一条 |
| **低** | 只找到相关主题，没找到结论 |

低置信度时**不许当结论用**，要说明"这条只是相关，不确定是不是你要的"。

## 常见错误（明令禁止）

- ❌ 凭印象回答"你之前说过……"却没有出处 → 一律禁止
- ❌ 为了显得聪明而拼凑两条不相关的记忆
- ❌ 找到相似内容就当命中，不给置信度
- ❌ 一次读五个大文件（超过 3 个文件还没命中，就该改成问宿主要关键词）

## 与其他技能的衔接

- 检索完发现该更新记忆 → `/symbio-memory-write`
- 新会话第一句 "/symbio-recall 读交接继续" → 走本技能第 0 层 + `symbio-handoff` 的开场流程
- 命中内容含 L2 → 引用时用占位符，不还原真值
