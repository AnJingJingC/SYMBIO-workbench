# 换会话交接（Handoff）

**这是 SYMBIO 最核心的一条纪律**：聊得越久，模型越笨、越贵。正确的做法不是硬撑到上下文塞满，而是**主动换一次干净的开始**，用一份交接文档续上。

## 什么时候该换（三个信号，命中一个就换）

1. 本轮已明显需要频繁回翻很早的消息
2. 开始重复问宿主已经回答过的事
3. 同一话题已推进 30 轮以上仍未收口

宿主没喊、但你判断该换时：**先问一句"建议现在交接换会话，同意吗"**，得到同意再执行。

## 步骤（严格按序，中途不许跳）

### 第 1 步：写交接（覆盖写 `当前交接.md`，硬顶 4KB）

只写四段，多一个字都删：

```markdown
# 当前交接（YYYY-MM-DD HH:mm）

## 当前状态
<这件事做到哪一步了，一句话>

## 下一步
1. <动作 + 文件路径>
2. <动作 + 文件路径>

## 未决问题
- <卡点 + 卡在谁/在哪>

## 关键路径
- 场景：memory/20-scenes/<场景>/
- 本次产出：<文件路径列表>
- 参考索引：<索引文件路径>
```

**不写**：过程中聊过的观点、被否决的方案、客套话、心情。这些进 `90-archive` 的会话摘要，不进交接。

### 第 2 步：沉淀增量到私有记忆

把本次会话真正**新增**的结论写进 `私有记忆.md`（走 `/symbio-memory-write`），而不是塞进交接。判断标准：下个会话不看它就做错事 → 必写；只是"知道了" → 不写。

### 第 3 步：归档旧会话摘要

在 `memory/90-archive/<场景>/YYYY-MM-DD-HHmm-会话归档.md` 写一份 300 字以内的摘要：
- 本次要解决的问题、结论、走过的弯路（弯路最有价值）
- 隐私处理：**只写占位符，不写任何 L1/L2 原文**

### 第 4 步：校验

```
node tools/memory-lint.mjs --scene knowledge-digest
```
必须全绿（尤其 `当前交接 ≤ 4KB`）。

### 第 5 步：给宿主一句可复制的续接指令

```
已交接。新会话请发：
/symbio-recall 读交接继续
```

## 新会话开场怎么接（写进本技能的对外说明）

新会话第一件事不是回答问题，而是：

1. 读 `AGENTS.md` → `config/symbio.config.json`（确认阶段）
2. 读 `memory/20-scenes/<场景>/当前交接.md`
3. 读 `身份卡.md` 与 `定位卡.md`（确认自己是谁、边界在哪）
4. 只看 `私有记忆.md` 开头几段（**不要全量读**）
5. 回一句"已接上：<当前状态>；下一步 <X>"，然后继续干活

## 失败与例外

| 情况 | 处理 |
|---|---|
| 交接超过 4KB | 把"过程记录"整段搬进归档，只留四段骨架 |
| 宿主不想换会话 | 照做，但把交接文档先写好（保险），并在回复里提示"上下文已重，风险自担" |
| 有敏感内容尚未脱敏 | **先脱敏再写交接**，宁可交接丢细节，也不让 L2 落进可同步文件 |
| 归档目录不存在 | 先建目录再写，不要跳过归档 |

## 红线

- 交接文档**永不写入**：密钥、身份证、银行卡、完整手机号、住址门牌、私聊原文。
- 交接写完必须校验体积；超限的交接等于没交接（新会话读不完就丢了）。
