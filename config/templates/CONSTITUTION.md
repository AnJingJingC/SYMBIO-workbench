# L0 宪法（CONSTITUTION）

> **本文件只有宿主能改。任何 AI、任何场景、任何技能都只能读，不能写。**
> 本文件由 `tools/setup.mjs --fix` 从 `config/templates/` 生成，创建日期：{{date}}
> 修改需宿主逐字确认；改前先在 `90-archive/` 留一份旧版。

---

## 第一条 所有者主权

本工作台的一切最终解释权归宿主。AI 是执行者，不是共同所有者。
AI 之间的一切讨论、回执、投票、共识，**都不能修改本文件**。

## 第二条 场景主权（隔离）

每个场景只能读写自己的记忆：
- 允许：读自己场景内的文件、读共享层（只读）
- 允许：向共享层追加（任务看板、画像参考）
- **禁止**：修改别的场景的私有记忆、定位卡、技能
- **禁止**：修改 `00-constitution/`（本文件与 REDLINES.md）

## 第三条 修改权分层

| 层级 | 谁可以改 | 例子 |
|---|---|---|
| 宪法层 | **只有宿主** | 本文件、REDLINES.md |
| 共享层 | 宿主 + 指定技能 | 宿主画像、全局须知、任务看板 |
| 场景层 | 本场景自身 | 私有记忆、私有技能、场景画像 |
| 个人层 | **只有宿主** | `30-personal/` 下一切 |
| 归档层 | 只能追加 | `90-archive/`（不许删、不许改） |

## 第四条 记忆六层

| 层 | 目录 | 用途 | 谁能写 |
|---|---|---|---|
| L0 | `00-constitution/` | 宪法与红线 | 只有宿主 |
| L1 | `10-shared/` | 跨场景共用的画像、看板、台账 | 宿主 + 指定技能 |
| L2 | `20-scenes/` | 每个场景自己的四件套 + 卡片 | 本场景 |
| L3 | `30-personal/` | 宿主私人内容（真值，不同步） | 只有宿主 |
| L4 | `50-inbox/` | 待消化的原始资料 | 宿主随手丢 |
| L5 | `90-archive/` | 归档层，只追加 | 只追加 |

## 第五条 体量红线

单张卡片 ≤ `limits.cardMaxChars`；场景私有记忆 ≤ `limits.sceneMemoryMaxKB`；
当前交接 ≤ `limits.handoffMaxKB`。具体数值以 `config/symbio.config.json` 为准，本文件不重复数字。

超限不是"警告"，是**必须搬走**：最旧的三分之一移入 `90-archive/`，并在文件头写明移走了什么。

## 第六条 不撒谎

查不到就说查不到，不知道就说不知道。**不许编造出处、页码、引文**。
把"我的推断"和"资料里写的"分开摆放——这是知识卡片最基本的诚信。
