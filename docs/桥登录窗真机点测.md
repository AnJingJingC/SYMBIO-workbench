# 桥窗口登录 · 真机点测指南（优先级 A）

## 目标
验证「免费 AI 桥」在**匿名额度耗尽**时，能经 HTTP 把站点窗口显出来让用户**手动登录**，且**绝不代填账号 / 验证码、不自动登录**（与作者仓库 `10-源码/免费AI桥` 的铁律一致）。

## 契约（代码层已固化）
- `POST /webai/show?site=doubao` —— 把豆包窗口显示出来，返回 `{ ok, visible, loggedIn, loginRequired, loginIndicator, contract, message }`。
- `POST /webai/hide?site=doubao` —— 登录完成后收回窗口到后台（登录态保留）。
- 桥只负责「开窗 + 如实报登录态」；登录动作必须由人完成。模拟登录会触发风控，明确不做。
- 面板「免费 AI 桥」卡片新增：「开登录窗 / 收回窗口」按钮 + 登录态灯（未检测 / 需登录 / 已登录），调用 `/api/symbio/bridge/login`、`/bridge/hide`（工作台服务端转发到桥）。

## 前置
1. 宿主已装 `symbio-workbench` ≥ 0.3.1（含面板登录按钮）。
2. 本机已启动伴生桥：
   ```
   cd E:/SYMBIO/shell
   npm run bridge          # = node launch.mjs --bridge-only
   ```
3. 把 `E:/SYMBIO/workbench` 升到 0.3.1（见 `docs/挂载操作指南.md` 升级三步，`replace:true`）。

## 自测步骤（任选其一）
### A. 用点测脚本（推荐，自动轮询登录态）
```
cd E:/SYMBIO
BRIDGE_URL=http://127.0.0.1:31239 node shell/test-login-window.mjs
```
脚本会：查桥在线 → 开窗读登录态 → 若未登录则每 5s 轮询、等你手动登录（最多 150s）→ 登录后发一句短问验证问答 → 收回窗口。
**退出码 0 = 全过；非 0 = 看 stderr。**

### B. 纯面板手测（不写脚本）
1. 面板「免费 AI 桥」卡片点「开登录窗」→ 豆包窗口弹出。
2. 若卡片显示「需登录（橙色）」：在弹出窗口里手动登录；刷新卡片或再次点「开登录窗」，应变「已登录（绿色）」。
3. 在「试问一句」输入短句 → 回车；应正常返回回答（不再 401 not-logged-in）。
4. 点「收回窗口」→ 窗口藏回后台，登录态保留。

## 判定标准
- 开窗成功、登录态如实回报（未登录≠不报、已登录≠误报）。
- 匿名额度耗尽时**第一反应是把窗口叫出来让人登录**，而不是静默失败或编造答案。
- 全程无任何自动填账号 / 验证码 / 自动登录行为。

## 已知边界（诚实）
- 真机点测需真实豆包账号 + 真实匿名额度耗尽场景；沙箱环境无法代跑（无 Electron / 无显示 / 无账号）。
- `answerSel` 的「登录态长期稳定性」此前未验收（选择器真机实测通过，但登录态下长期问答未复验）；本测顺带覆盖登录后首轮问答。
