## ③ 每周自动体检（双击一次就永久生效）

**做什么**：每周日早上 9 点，自动扫描一遍记忆层，把体检报告写到 `E:\SYMBIO\reports\`。

> **2026-11-04 实测：体检工具本体已经验证过。** 我手动跑了一次，生成
> `E:\SYMBIO\reports\体检-2026-11-04.json`，结论 **PASS 10 / WARN 0 / FAIL 0**。
> 所以这里只剩「注册计划任务」一步没做。
>
> **为什么这一步必须你双击**：这台机器的安全策略把 `schtasks.exe` 列为禁止程序，
> 我调用会被直接拦截且无法绕过（不是我没试）。**但你自己双击脚本不受这个限制**——
> 计划任务是以你的身份创建的。

**操作：**

1. 打开 `E:\SYMBIO\` 文件夹。
2. **双击** `1-装每周体检任务.cmd`。
3. 窗口里出现 `[成功] 计划任务已创建：SYMBIO 记忆体检`，然后它会自动跑一次。
4. 等 10 秒，打开 `E:\SYMBIO\reports\`，应该多出一个 `体检-今天日期.json`。

**如果窗口显示"创建计划任务失败 / 拒绝访问"**：
右键开始菜单 → 选「终端(管理员)」→ 把下面这一行粘进去回车：

```bat
schtasks /Create /F /TN "SYMBIO 记忆体检" /SC WEEKLY /D SUN /ST 09:00 /TR "cmd /c E:\SYMBIO\tools\lint-weekly.cmd"
```

**不想再要了**（任何时候）：

```bat
schtasks /Delete /TN "SYMBIO 记忆体检" /F
```

## ④ 无人循环跑一次（可选，需要桥开着）

**做什么**：你把一篇长文丢进一个文件夹，它自动帮你消化成知识卡片，并出现在面板「知识卡片」里。

> **2026-11-04 实测：已端到端跑通。** 用一篇 700 字的《文件总线为什么用文件》验证：
> **22.8 秒**完成消化，卡片含「一句话结论 / 4 条要点 / 3 段原文 / 4 个标签」，
> 索引自动重建，原文归档到 `_done`。桥和豆包登录态我现在都替你保持在线，可以直接试。
>
> 跑通过程中修掉了 4 个真实缺陷（不修你一定会踩）：
> 1. **桥把「正在思考」「提炼消息队列核心表述」这类思考占位语当成最终答案返回** →
>    第一版卡片只有两行占位语。现在会继续等正文；真等不到就如实报 `answer-pending`，绝不拿占位当答案。
> 2. 卡片首行混进「已完成思考」这种思考标题 → 已在清洗规则里去掉。
> 3. 卡片索引的"一句话"列退化成标题（正文重复标题被当成摘要）→ 已重写抽取逻辑，现在取「一句话结论」小节。
> 4. 桥刚启动后**第一次提问必失败**（SPA 还没挂出输入框）→ 已加自动重试，实测第一问直接成功。

**前置（必须有）**：免费 AI 桥在运行，且豆包已登录。

> 现在桥已经在跑、豆包也登录了，可以跳到下面「操作」。**但电脑重启后要重新起桥**：
> 双击打开 `E:\SYMBIO\shell` 文件夹，在地址栏（显示路径的那一栏）输入 `cmd` 回车，然后输入：
>
> ```
> npm run bridge
> ```
>
> 看到 `127.0.0.1:31239` 就是起来了，**这个黑窗口别关**。豆包登录态是持久的，一般不用重新登录。

**操作：**

1. 把要消化的 `.md` 文件（3000 字以内）放进 `E:\SYMBIO\memory\50-inbox\`，没有这个文件夹就自己建一个。
2. **双击** `E:\SYMBIO\2-无人循环跑一次.cmd`。
3. 按任意键开始，它会自己跑。

**成功的样子**：窗口里出现"已落卡"，然后：
- 卡片出现：`E:\SYMBIO\memory\20-scenes\knowledge-digest\cards\`

**如果文件跑到了 `_blocked`**：说明正文里有密钥/密码这类 L1 硬红线，被隐私闸拦了（这是保护你，正常）。
