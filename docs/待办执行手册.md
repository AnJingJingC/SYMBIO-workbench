## ③ 每周自动体检（双击一次就永久生效）

**做什么**：每周日早上 9 点，自动扫描一遍记忆层，把体检报告写到 `E:\SYMBIO\reports\`。

**操作：**

1. 打开 `E:\SYMBIO\` 文件夹。
2. **双击** `1-装每周体检任务.cmd`。
3. 窗口里出现 `[成功] 计划任务已创建：SYMBIO 记忆体检`，然后它会自动跑一次。
4. 等 10 秒，打开 `E:\SYMBIO\reports\`，应该多出一个 `体检-今天日期.json`。

**如果窗口显示"创建计划任务失败 / 拒绝访问"**：
右键开始菜单 → 选「终端(管理员)」→ 把下面这一行粘进去回车：

```bat
schtasks /Create /F /TN "SYMBIO 记忆体检" /SC WEEKLY /D SUN /ST 09:00 /TR "cmd /c E:\SYMBIO\tools\lint-weekly.cmd"
```

**不想再要了**（任何时候）：

```bat
schtasks /Delete /TN "SYMBIO 记忆体检" /F
```

## ④ 无人循环跑一次（可选，需要桥开着）

**做什么**：你把一篇长文丢进一个文件夹，它自动帮你消化成知识卡片，并出现在面板「知识卡片」里。

**前置（必须有）**：免费 AI 桥在运行，且豆包已登录。
起桥方法：双击打开 `E:\SYMBIO\shell` 文件夹，在地址栏（显示路径的那一栏）输入 `cmd` 回车，然后输入：

```
npm run bridge
```

看到 `127.0.0.1:31239` 就是起来了，**这个黑窗口别关**。

**操作：**

1. 把要消化的 `.md` 文件（3000 字以内）放进 `E:\SYMBIO\memory\50-inbox\`，没有这个文件夹就自己建一个。
2. **双击** `E:\SYMBIO\2-无人循环跑一次.cmd`。
3. 按任意键开始，它会自己跑。

**成功的样子**：窗口里出现"已落卡"，然后：
- 卡片出现：`E:\SYMBIO\memory\20-scenes\knowledge-digest\cards\`
- 原文被移走：`E:\SYMBIO\memory\50-inbox\_done\`
- 面板打开，「知识卡片」数字 +1

**如果文件跑到了 `_blocked`**：说明正文里有密钥/密码这类 L1 硬红线，被隐私闸拦了（这是保护你，正常）。
**如果跑到了 `_too-long`**：正文超过 3000 字，自己切成两篇。

## ⑤ 校准三个新站点（可选，不校准就别用它们）

除了豆包，我还加了 DeepSeek、通义千问、智谱三个站点，但**选择器是按经验猜的，没在你的机器上验证过**。所以要先用一条命令探测。

**操作：**

1. 先按 ④ 的方法把桥起来（`npm run bridge`，窗口别关）。
2. 再开一个 CMD 窗口（任意文件夹，地址栏输入 `cmd` 回车）。
3. 输入下面命令，回车：

```
E:\SYMBIO\3-桥站点校准.cmd
```

或者直接双击 `E:\SYMBIO\3-桥站点校准.cmd`（它会问你要校准哪个站，回车默认 doubao）。

**结果怎么看：**

| 输出 | 含义 | 你要做什么 |
|---|---|---|
| `calibrated: true` | 全对 | 直接能用，告诉我一声，我把该站标成已验证 |
| `loggedIn: false` | 该站没登录 | 要先手动登录（见下） |
| `matched: {input: false}` | 我的选择器猜错了 | 把窗口里 `dom` 那一段复制发我，我按实际页面改 |
| `桥不可达` | 桥没起 | 回去起桥 |

**手动登录某个站**（壳绝不替你填账号，这是铁律）：浏览器地址栏输入下面这一行回车，会开出一个窗口，你在里面自己登录；登完再把 `show` 改成 `hide` 发一次：

```
http://127.0.0.1:31239/webai/show?site=deepseek
http://127.0.0.1:31239/webai/hide?site=deepseek
```

（`deepseek` 换成 `qianwen` 或 `zhipu` 即可。注意这两个地址只接受 POST，如果浏览器直接打开报错，就在 CMD 里用 `curl -X POST` 的方式发。）

## ⑥ 跨场景派单（可选，验证"总线"能用）

```
cd /d E:\SYMBIO
node tools\bus.mjs dispatch --from deep-research --to knowledge-digest --task "把调研卡片归档进知识卡目录" --accept "卡片在 cards 且索引更新"
```

它会返回一个 8 位 hash。然后：

```
node tools\bus.mjs receipt --hash 你拿到的hash --status done --result "已归档"
```

**成功的样子**：派单后看板多一行；回执后看板恢复成"（当前无未闭环任务）"，并且 `E:\SYMBIO\memory\90-archive\任务台账-2026-11.md` 多一行。
