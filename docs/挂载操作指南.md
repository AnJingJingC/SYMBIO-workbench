## 1. 三步装进去

### 第 1 步 · 在 DSH Desktop 里开一个新会话

宿主现在正在运行（本机查到 5 个 `DSH Desktop` 进程）。打开窗口，点「新会话」，用普通会话即可。

### 第 2 步 · 粘提示词

打开 `E:/SYMBIO/workbench/INSTALL-PROMPT.txt`，**全文复制**粘进对话并发送。

它会让宿主里的 Agent：
1. 先探测本会话是否真有 `install_local_workbench` 工具（不靠文档猜）；
2. 调用 `install_local_workbench({ path: "E:/SYMBIO/workbench/symbio-workbench-0.1.0.tgz", replace: false })`；
3. 如实报告返回的 `application` 值。

**会弹一次权限审批**（`danger-full-access`）——因为装进共享 Profile 的代码运行在沙箱外。这是宿主的安全设计，手动点同意即可；别让 Agent 绕过。

### 第 3 步 · 看结果

| `application` | 怎么做 |
|---|---|
| `applied` | 直接生效，去左侧栏找面板 |
| `restart-required` | **手动**点菜单「Harness → 重启 Harness」（通常只需重启 Harness，不用退出应用） |
| `failed` / `cancelled` / `overridden` | **未生效**，不要当成装好了；把报错发回对话排查 |

> 规范明确：Agent 不得自行关闭/重启 DSH Desktop 或 Harness，也不得用进程命令探测。提示词里已写死这条约束。

## 2. 重启后去哪找

1. 展开左侧栏 → 左上角「工作台」右侧的当前名称／切换区 → 选 **「SYMBIO 工作台」**。
2. 没看到？进「**工作台市场 → 已安装**」，找带「**本地**」标识的 `symbio-workbench`，检查运行状态，加载/启用后再切换。
3. 本地工作台加载后会自动进切换菜单，**没有单独的「添加」按钮**。

验收：面板能显示、接口不报错、窄窗不出现单字竖排或横向溢出；桥未启动时应显示「离线」而不是假在线。

## 4. 为什么必须走这一步，不能我直接改文件

工作台包会写宿主的共享 Profile，宿主把这件事**唯一授权给 Plugin Manager**（`install_local_workbench` → `installBundle`）。工具实现里明确写着：

- 需要 `approveEscalation` 提权审批；
- 审批被拒**不得**用 CLI 或改 Profile 文件绕过；
- 只有 `applied` 才算生效。

我这边能做的是把包做对、把校验跑完、把提示词写好；**点击审批和确认安装只能由你在 DSH Desktop 里完成**。

## 8. 升级到 v0.3.0（工具箱：面板内直接驱动 6 工具）

### 为什么没有用「scoped Agent 工具」

复核 DSH Desktop 工作台契约后发现：工作台能注册的只有 **业务面板** 与 **自己的 `/api/<id>/*` 路由**，规范里 `tool` 一词只出现在「安装脚本审批」语境，**没有「scoped Agent 工具」这个注册位**。所以「对话里直接调 6 工具」在原契约下做不到。

S3 的精神（把 6 工具接入工作台、可在面板调用）改用契约允许的方式落地：工作台服务端（`apply()` 跑在 Node 侧，本机已是 `danger-full-access`）直接用 `execFile` 跑 `E:/SYMBIO/tools/` 下的白名单脚本，结果回显到面板。

### 变了什么

| | 0.2.0 | 0.3.0 |
|---|---|---|
| 面板 | 只读实况（队列/卡片/记忆/花费/桥/红线） | 同上加 **「工具箱」卡片**：选工具→填参数→点运行→看退出码与输出 |
| 接口 | `/state`、`/ask` | 加 `GET /tools`、`POST /tools/run` |
| 能力 | 只能看 | 能直接跑 `pii-scan`/`memory-lint`/`index-build`/`spend-guard`/`model-probe`/`load-gate` |
| 安全 | — | 白名单 6 文件 + 无 shell + 参数净化 + 超时 60s + cwd=E:/SYMBIO |

### 三步升级

1. 包已打好：`E:/SYMBIO/workbench/symbio-workbench-0.3.0.tgz`（如需重打：`cd E:/SYMBIO/workbench && npm run verify` 应 16/16 → `pnpm pack`）。
2. 在 DSH Desktop 开新会话，全文复制 `E:/SYMBIO/workbench/INSTALL-PROMPT.txt` 粘进去发送（用 `replace: true`）。
3. 看 `application`：`applied` 直接生效；`restart-required` 手动点「Harness → 重启 Harness」；其余值不算生效。

### 升级后验收清单（在 0.2.0 基础上新增）

- 面板多出一张 **「工具箱」** 卡片，列出 6 个本机工具。
- 选「负载闸」→ 点「运行」→ 应看到 `exit=0` 与真实 CPU/内存（约 3~4s）。
- 选「隐私扫描」→ 贴一段含手机号的文本、勾 `--redact` → 点运行 → 看到脱敏结果。
- 选「预算硬闸」→ 在数额框留空点运行（只读判定）→ 看到 GO/CAUTION/STOP。
- 所有运行都返回真实退出码，无 shell、不越权；输入里的换行与 `;|&` 等字符被剥离。

### 实测基线（本机已验证）

`execFile` 链路对真实工具跑通：`model-probe` exit 0（3266 字）、`load-gate` exit 0（CPU 17.2% / 内存 64.7%）、`spend-guard` 判 CAUTION、`memory-lint` FAIL 0。面板 UI 的真机点测留待用户侧确认。
